Sharepic generator

Welcome to the Rheinos-and-RheinIIs-Social-Media-Sharepic-Generator-Overview-Page

I couldn't make this word any longer. Here's an overview over out templates :)

Standard posts

Short post (with subtitle)

A short post with a title, optional subtitle, and date.

Announcement Post

Template for all kinds of announcements.

Open Training Announcement Post

Template to announce open trainings.

Message Post

Template to spread a message we want to spread. Can be used as the first picture on an informational recruitment post (e.g. "Quadball is mixed Gender").

Informational Post

Use this template for informational content, e.g. to explain the rules of Quadball. In most cases it makes sense to use a message template picture for the first picture of the post, then multiple informational pictures and at the end an open training info picture.

Open Training Info Picture

Put this template at the end of recruitment posts. It should contain details about the open training.

Tournament posts

Score Post (square)

Template to post the result of a game after a game (square format).

Score Story (vertical)

Template to post the result of a game after a game (vertical format for story).

Schedule Post

Template to announce league gamedays and other events with a schedule (e.g. tournament group stages). If there are more than five games scheduled, split the schedule equally on multiple pictures, which should be posted in a single post. To announce a single game (e.g. a knockout stage game), use the announcement template instead!

Roster Post

Template to post our rosters, should be self-explaining.

Medal Post

Template for when we've reached a top 3 placement on a bigger tournament. For lower placements or less relevant tournaments, use the standard template and put the placement in the caption.

Special Score Story

Special Roster Post

Alternate special design for a team lineup.

Special Medal Post
